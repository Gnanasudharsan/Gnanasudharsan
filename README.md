## 02 — GPU Inference Performance Lab
**PyTorch · CUDA · Triton · Metal/MPS · Kernel Fusion · CUDA Graphs · Benchmarking**

A reproducible performance-engineering lab for latency-sensitive small-batch inference.

**Measured work includes**
- Reduced kernel launches from **64 → 8** for small-batch fused execution on Apple M4
- Achieved up to **1.26×** fused-kernel speedup on measured MPS workloads
- Measured **1.98×** speedup using CUDA Graph replay on NVIDIA T4
- Built paired/interleaved benchmarking with confidence intervals and provenance
- Investigated launch overhead, memory bandwidth, serving goodput, regressions, and hardware-specific failure modes
